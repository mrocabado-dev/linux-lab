    # Mapa del Sistema de Archivos Linux

## /

- Directorio raiz del sistema Linux.
- Todos los directorios parten desde aqui.

## /home

- Contiene los archivos personales de los usuarios.
- Ejemplo:
/home/mateo

## /etc

- Contiene configuraciones del sistema.
- Ejemplos:
  - passwd
  - hosts
  - ssh

## /var

- Guarda datos variables.
- Ejemplos:
  - logs
  - cache
  - archivos web

## /bin

- Contiene comandos esenciales.
- Ejemplos:
  - ls
  - cp
  - mv

## /usr

- Programas y librerias del sistema.

## /tmp

- Archivos temporales.

## /boot

- Archivos necesarios para iniciar Linux.

## /dev

- Dispositivos representados como archivos.

## /proc

- Informacion de procesos y kernel.

## /sys

- Informacion de hardware y drivers.
