
# Ejemplos Practicos de Navegacion Linux

## Ver ubicacion actual

```bash
pwd
```

## Ir al directorio raiz

```bash
cd /
```

## Volver al home

```bash
cd ~
```

## Listar archivos

```bash
ls
```

## Ver archivos ocultos

```bash
ls -la
```

## Ver estructura de carpetas

```bash
tree -L 2
```

## Ver espacio en disco

```bash
df -h
```

## Ver tamaño de carpetas

```bash
du -sh *
```

## Ver informacion del sistema

```bash
uname -a
```

## Buscar archivos

```bash
find /etc -name "hosts"
```
