# Semana 08 - Arrays y Matrices en Bash

## Objetivo

Desarrollar un inventario automático del repositorio linux-lab utilizando arrays indexados, arrays asociativos y matrices simuladas en Bash.

## Archivos

| Archivo              | Descripción                      |
| -------------------- | -------------------------------- |
| inventario.sh        | Script principal                 |
| commands-used.md     | Documentación de comandos        |
| inventario-report.md | Reporte generado automáticamente |

## Uso

Analizar el repositorio actual:

```bash
./inventario.sh
```

Analizar otro directorio:

```bash
./inventario.sh /ruta/directorio
```

## Técnicas Aplicadas

* Arrays indexados
* Arrays asociativos
* Matrices simuladas
* mapfile
* column
* printf
* Reportes Markdown
