# Commands Used

## chmod

Dar permisos de ejecucion.

```bash
chmod +x backup-check.sh
```

---

## find

Buscar archivos.

```bash
find ~/backups -name "*.tar.gz"
```

---

## wc -l

Contar lineas.

```bash
wc -l
```

---

## du -sm

Ver tamanio en MB.

```bash
du -sm ~/backups
```

---

## awk

Extraer columnas.

```bash
awk '{print $1}'
```

---

## tee -a

Guardar salida en archivo y pantalla.

```bash
tee -a logs/backup-check.log
```

---

## mkdir -p

Crear directorios.

```bash
mkdir -p logs
```

---

## touch

Crear archivos vacios.

```bash
touch backup.tar.gz
```

---

## sort

Ordenar resultados.

```bash
sort
```

---

## tail -1

Obtener ultimo elemento.

```bash
tail -1
```
